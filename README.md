# 湖西懐かし写真館

公開URL: https://kosaialb.atawi.link/

磐田・袋井懐かし写真館の思想とUIを継承した、湖西市（旧新居町を含む）の地域写真アーカイブです。公開写真の出典・撮影時期・利用条件・加工内容を `data/photos.json` に記録し、各詳細ページへ表示します。AI生成の歴史写真は使用していません。

## 公開と運営

Cloudflare Worker `kosai-album`、専用D1、非公開R2を利用します。寄稿・問い合わせは専用台帳に保存され、自動メール転送はありません。担当者は `npm run operator` で運営画面を開きます。本人が掲載版へ同意してから公開する仕組みです。原本と連絡先は公開リポジトリに保存しません。

`npm test` で隔離された受付・許諾・公開・撤回フローと全写真・ページを確認します。`npm run dev` でローカル表示確認、`npm run deploy` で既存の専用Workerへ反映します。スキーマ更新は `npx wrangler d1 migrations apply kosai-album --remote` で適用します。

## 不動産への案内

トップ・写真詳細・駅特集・作成者・相談ページ・フッターから、富士ヶ丘サービスの無料実家カルテへ案内します。UTMで掲載位置を区別します。寄稿情報は送客URLへ含めません。写真寄稿は不動産相談の申込みではありません。実際の送客件数や成約効果は未測定です。

## デザイン

紙のアルバムを思わせる背景に、浜名湖をイメージした深い青緑を使用。見出し・本文はゴシック体。PCと狭幅でも作成者・寄稿・実家相談の3導線を表示します。転載条件未確認の市公式写真は複製せず資料案内からリンクします。
